# GymCompass

Interactive muscle map and workout guide.

## Planned Features

- Click a muscle area (chest, shoulders, arms, back, abs, legs)
- Exercises, gym machine usage and form tips
- Workout log and progress archive
- Nutrition and supplement info
- English and Turkish support

## Status

Work in progress.

## Disclaimer

General information only, not medical or personal trainer advice.
